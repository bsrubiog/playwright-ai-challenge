# Desafío Técnico: Automatización E2E con Playwright e Integración de IA

Framework de pruebas de extremo a extremo (E2E) desarrollado en **TypeScript** y **Playwright**, integrado con la API de **Google Gemini** para la generación dinámica de datos sintéticos y validaciones semánticas en la interfaz de usuario.

---

## 🛠️ Stack Tecnológico
- **Lenguaje:** TypeScript / Node.js
- **Core Test Library:** Playwright Test
- **Gestor de Dependencias:** NPM
- **Motor de Inteligencia Artificial:** Google Gemini API (`gemini-1.5-flash`)
- **Reportes:** Playwright HTML Reporter

---

## 🚀 Requisitos Previos
- **Node.js:** v18 LTS o superior instalado en el equipo.
- **Gestor de paquetes:** NPM.

---
